# Hello there

This is my([Aaron Kemner](https://www.aaronkemner.com/)) personal collection of tools 'n gadgets for UE5, nicely wrapped up in a Plugin for ease of use.

# Notable Feature:
## Blueprint Reference Skeleton Function Library
Exposes `FReferenceSkeleton` to Blueprints via `FBlueprintReferenceSkeleton` as well as functions that use it

## Draw Hierarchy AnimNode
An AnimNode that adds debug drawing for bones. 
Can be used similarly to a pose watch, but it also works in development builds, and can be applied to only a part of the hierarchy.
